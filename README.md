# Stroke Trends Analytics Dashboard — Tableau

## Overview
Interactive Tableau dashboard analyzing stroke trends across patient age,
gender, and occupation using clinical health data.

## Tools
- Tableau
- Excel / CSV data processing

## What the Dashboard Shows
- Stroke incidence by age group and gender
- Occupational risk factors correlated with stroke frequency
- Geographic and demographic trend analysis

## Key Outcome
Transforms raw clinical data into visual insights that support
public health awareness and preventive care strategies.

## Skills Demonstrated
Tableau · Data Visualization · Healthcare Analytics · Clinical Reporting
